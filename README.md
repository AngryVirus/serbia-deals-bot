# Где дешевле? Сербия

Отдельный Telegram-бот **@SerbiaDealsBot** для поиска товаров и сравнения корзины.
Владелец — Telegram ID `340780041` (@AngryVirus).

**Статус:** бот активирован в Telegram Serverless. В опубликованном каталоге
127 505 предложений Lidl, Maxi / Delhaize, Okov, Gomex, Matijević, Lilly, METRO и Aman.
Для регулярного обновления подготовлен ограниченный список этих восьми источников;
служебная проверка уведомлений о правах работает отдельно. Результаты публикаций и ограничения —
[состояние релиза](docs/RELEASE_STATUS.md).

## Что реализовано

- Поиск сначала показывает сети с диапазоном цен. Внутри сети — товары;
  одинаковые GTIN объединяются, в карточке указаны цены по форматам сети.
  Адреса филиалов не выдумываются.
- Список корзины можно вводить через запятую или с новой строки. Для ещё
  не выбранных товаров доступен явно обозначенный предварительный подбор;
  подтверждённые товары сравниваются точно по их идентификаторам.
- Четыре основных пункта: поиск, корзина, уведомления, помощь.
- Меню в виде компактных динамических изображений с иллюстрацией покупок на фоне Белграда, кремовым фоном и синими
  акцентами и локальными иконками. Основные экраны, товары и сравнение — компактные
  изображения с кнопками; подробности открываются отдельно. [Интерфейс](docs/INTERFACE.md).
- По умолчанию названия показаны из прайса без ожидания перевода. В списке и карточке
  есть отдельная кнопка перевода: русский перевод / сербский оригинал. Бесплатный перевод
  публичных названий с общим ограниченным кэшем и резервным сервисом; личные
  запросы внешним сервисам не передаются.
- Поиск по русским названиям распространённых категорий и сочетаний («сливочное масло»,
  «оливковое масло», «корм для кошек»), сербская латиница/кириллица,
  поиск по штрихкоду. Это небольшой проверенный словарь, не универсальный переводчик.
- Необязательные уточнения для любых товаров с доступными вариантами: бренд,
  объём или вес; в подходящих категориях — вид, жирность и цоколь. Без выбора
  кнопка «Показать все» сохраняет общий поиск. Уже указанные признаки не спрашиваются.
  Патроны и переходники исключаются из поиска лампочек.
- Старая кнопка не заменяет уже подтверждённый товар. Повторные и параллельные
  добавления не превышают лимит корзины; список добавляется целиком.
- Корзина до 30 позиций; ввод списком до 20 строк, выбор конкретных товаров,
  количество упаковок/штук, сохранение и удаление позиций.
- Сравнение полной одинаковой корзины в одной сети и распределения покупок между
  сетями. В кратком сравнении явно указано, где найдена только часть списка;
  состав и сумма магазина открываются отдельной кнопкой.
- Отслеживание конкретного товара и уведомления о снижении цены; выключение
  уведомлений, удаление своих данных.
- Админка с ролями модератора, администратора и владельца по числовому ID:
  статистика пользователей, команда, баны и аудит за 10 дней. Возможности
  скрываются и проверяются согласно роли. [Управление](docs/ADMINISTRATION.md).
  Состояние источников отделено от ручного запуска сборщика.

## Архитектура

`serverless/tgcloud/` — самостоятельные JavaScript-обработчики и SQLite.
`collector/` — Python 3.12+, стандартная библиотека, официальные CSV и GitHub Actions.
Render, Supabase и платные API не используются.

Оформление и правила полномочий команды соответствуют боту вакансий.
Схема данных, поиск, импорт, корзина и очередь написаны для товаров; таблицы
имеют отдельный префикс `sd_`. Данные и ключи @SerbiaJobsBot не используются.

## Источники и границы сравнения

В реестре 47 проверенных по происхождению наборов открытых данных. Во время
аудита **32 набора успешно скачались и разобрались**, остальные 15 не предоставили
пригодного свежего CSV в этой среде. Это не обещание доступности всех 47 сетей.
Подробности — [проверка источников](docs/SOURCES.md),
[машиночитаемый результат](docs/SOURCE_AUDIT.json).

Текущий прайс отделяется от истории; конфликтующие цены и старые файлы
не используются. Неудачная или неполная загрузка не заменяет последнюю
опубликованную версию. Магазин, дата прайса и дата получения видны на карточке.
Ссылки на официальные прайсы доступны в «Помощи».

**Цена сети может быть максимальной сводной ценой**, а не ценой ближайшего
филиала. Остатки, персональные купоны и стоимость поездки не подтверждаются.
«Самое дешёвое» означает среди свежих проверенных предложений в каталоге.

Одинаковые товары объединяются только по проверенному внешнему GTIN. Внутренние
коды магазина остаются локальными. В первой версии корзина сравнивает выбранные
товары и упаковки; замена бренда или модели без подтверждения не выполняется.
Нормализация цены за кг/л по ненадёжным исходным полям не применяется.

## Проверка локально

```sh
npm ci --ignore-scripts --prefix serverless
python3 -m unittest discover -s tests -v
node --test serverless/tests/*.test.js
python3 -m collector.collect --sources lidl,maxi,okov --budget 180
```

Сборщик по умолчанию выполняет **dry-run**, без публикации и отправки сообщений.
Для чтения CSV ключи не нужны. `--publish` требует отдельного ключа Serverless.

Тесты покрывают поиск, CSV, атомарную публикацию поколений, параллельные запросы,
корзину, поддельные callbacks, удаление данных, очередь, 429, неопределённые
результаты доставки, подавление предупреждений и PNG-рендеринг.

Локальная проверка реальных данных трёх сетей: 104 091 предложение, импорт
17,1 секунды, поиск «лампочка E27» около 4 мс, SQLite около 125 МиБ.
[Результат](docs/PERFORMANCE.json) относится к локальной машине; время запросов,
квоты и размер базы в Telegram Serverless нужно подтвердить отдельно.

## Подключение и запуск

См. [инструкцию развёртывания](docs/DEPLOYMENT.md).
Плановый сбор обновляет только проверенный список `collector/enabled-sources.json`.
Явное значение `false` у соответствующей Repository variable отключает расписание.
Автоматической активации самого бота при push нет. Сначала отдельный ключ, stage, проверка импорта и лимитов,
затем явная операция activate после разрешения владельца.

Лицензии встроенных шрифтов DejaVu и кодека pako:
[tools/licenses](tools/licenses). Открытые прайсы распространяются под Serbian
Open Data License; необходимо сохранять указание издателя и дату получения.
