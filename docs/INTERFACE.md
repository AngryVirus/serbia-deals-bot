# Интерфейс покупок

В обычном меню четыре пункта: поиск одного товара, корзина, уведомления и помощь.
Сотрудники дополнительно видят вход в администрирование согласно своим правам.

- Поиск: название → кнопка сети с диапазоном цен → варианты товара → карточка.
  Экран выбора сети — картинка в общем стиле бота. Названия товаров и подробные
  цены остаются текстом, который можно скопировать. Диапазон сети может включать
  разные упаковки; он не выдаётся за цену одного одинакового товара.
- Корзина: добавление списка → предварительное сравнение. На странице до пяти
  позиций. Кнопка с названием позиции открывает изменение количества, уточнение
  упаковки и удаление. В пустой корзине кнопки сравнения нет. Возврат в корзину
  отменяет ожидание ввода списка. При уточнении товара можно вернуться к корзине.
- Уведомления: видны состояние и количество отслеживаемых товаров. Показана одна
  кнопка: включить либо выключить. Добавление товара для отслеживания выполняется
  из его карточки.

Изображения создаются внутри Serverless; отдельный хостинг не требуется.
При подтверждённой ошибке построения или неподдерживаемом формате изображения
доступно текстовое меню с теми же кнопками.

Проверки: `serverless/tests/interface.test.js`, общие тесты корзины и модерации,
локальная отрисовка PNG. Приватная операция `diagnose` проверяет меню, поиск,
корзину, существующую позицию владельца (если есть), уведомления и админку
через виртуальный Telegram API, без отправки сообщений и изменения корзины.
Она не заменяет проверку отображения кнопок в приложении Telegram.
