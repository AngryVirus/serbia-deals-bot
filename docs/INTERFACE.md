# Интерфейс покупок

В обычном меню четыре пункта: поиск, корзина, уведомления и помощь. Сотрудникам
доступен отдельный вход в администрирование согласно их полномочиям.

Все основные экраны оформлены картинками с кнопками: компактная иллюстрация,
крупный заголовок, локально нарисованные иконки. Изображение текущего сообщения
заменяется при переходе. В случае подтверждённого отказа картинки работает
текстовый вариант с теми же действиями. Внешний хостинг изображений не нужен.

- Поиск: название → сеть с диапазоном цен → три товара на странице → карточка.
  Короткие кнопки с номером и ценой соответствуют товарам на картинке.
  Названия по умолчанию из прайса. После явного перевода: русский / сербский.
- В карточке: цена, магазин, дата, характеристики. Добавление в корзину и
  отслеживание находятся рядом. Цены отдельных форматов сети открываются
  отдельно, если для товара есть несколько таких прайсов. Это не адреса филиалов.
- Корзина: список через запятую или с новой строки → сравнение. На странице до
  пяти позиций; номерная кнопка открывает количество, уточнение упаковки и удаление.
  Возврат к корзине отменяет ожидание ввода списка.
- Сравнение: две сети на странице с составом и ценами. Неполные корзины явно помечены
  «Только N из M». Кнопка магазина открывает состав с итогом, по пять позиций.
  Покупки в разных сетях доступны отдельно, когда найден весь список.
- Уведомления: статус, количество товаров и одна кнопка включения/выключения.
  После нажатия «Следить» можно сразу включить уведомления. Список отслеживания
  разбит на страницы по пять товаров.
- Помощь: три коротких сценария и связь с поддержкой. Ссылки на прайсы, сведения
  о машинном переводе и удалении данных находятся в «О ценах и данных».

## Названия товаров

По умолчанию список и карточка показывают оригинал из прайса без запросов к
переводчикам. Кнопка «Перевести названия» в списке и «Перевести название» в
карточке включает перевод только этого экрана. «Оригинал» возвращает исходный
вид; переходы и новые поиски не запускают перевод автоматически. Поиск по
русским словам и уточнения продолжают работать через локальный словарь.

Переводятся только публичные названия из каталога. Личные поисковые запросы и
неуточнённые строки корзины внешним сервисам не отправляются. Бренд, сербский
оригинал и идентичность товара сохраняются; числовые характеристики проверяются.
Google Translate используется с бесплатным резервом MyMemory, без ключей и
платной подписки. При квоте сервис временно не вызывается. Если перевод не
получен, показаны «Перевод недоступен / сербское название» и рабочие кнопки.
Для простых частых названий есть локальный словарь.

Общий кэш ограничен 3 000 публичных названий, срок перевода — 30 дней. Атомарные
аренды подавляют параллельные запросы одного названия; общий лимит — 120 новых
переводов в минуту, не более трёх одновременно на один экран. Повтор после сбоя
не раньше минуты. Сбой кэша не блокирует поиск и карточки. В длинных списках
сокращаются обе части названия с сохранением окончания, а не только сербская.

## Проверки

`interface.test.js`, `product-names.test.js`, тесты корзины и модерации проверяют
переходы, права, сравнение неполных корзин, изоляцию личных данных, кэш, квоты,
параллельный перевод и резервный сервис. Локально просматриваются JPEG в том же режиме, что в боте.
Приватная операция `diagnose` использует виртуальный Telegram API и проверяет
экраны покупок, админку и перевод публичных контрольных названий без сообщений
пользователям и изменений корзины. Кэш перевода может пополняться.

## Необязательные уточнения для любых товаров

Перед результатами бот предлагает подходящие уточнения: бренд и упаковку
(объём либо вес) по данным публичных предложений. В подходящих категориях есть
вид товара; для молочных продуктов — жирность, для лампочек — цоколь.
Если полезных альтернатив нет, поиск продолжается сразу. Штрихкод не требует вопросов.
Уже указанные в запросе бренд и размер повторно не спрашиваются.

На первом экране достаточно нажать «Показать все»: ни один необязательный
фильтр не применяется. Выбранные ограничения можно отменить. Уточнения доступны
и при выборе конкретного товара для позиции корзины; сам список без уточнения
сравнивается сразу по всем подходящим вариантам.

Подсказки используют ограниченную выборку до 120 совпадений и до 24 значений
каждого признака. Это не ограничивает поиск всех предложений. Варианты упаковки
зависят от выбранного бренда; смена бренда или вида сбрасывает зависимые параметры.
Вид мяса уточняется отдельно: курица, говядина, свинина, индейка. Общий запрос
«мясо» охватывает эти виды и исключает готовые продукты и корма существующими правилами.

250 мл и 0,25 л, 500 г и 0,5 кг сопоставляются по названию товара, без доверия
к неоднозначному полю единиц измерения источника. Индексы, свежесть, ограничения
по пользователю и защита чужой корзины сохраняются. Черновик уточнений привязан
к пользователю, действует 15 минут, отменяется новым поиском и не применяется повторно.

## Возврат к общему поиску

Выбранные уточнения видны над результатами. Если предложений с ними нет,
доступна кнопка «Показать без уточнений»: она сохраняет запрос и выбранную
позицию корзины, снимая только дополнительные ограничения. Старая кнопка не
может изменить новый поиск. Открытие редактирования и выход без применения
сохраняют действующие параметры.

Уточнения можно вписать сразу: «молотый кофе», «кофе в зернах», «зелёный чай»,
«куриное филе». Распознанный вид повторно не спрашивается. Название категории
проверяется как отдельное слово: «чайник» не получает виды чая.

В профиле переданные поля-объекты заменяются целиком одним SQL-обновлением:
сброс не сохраняет прежние вложенные значения и не затирает независимые поля.

## Видимость ответа и энергетики

Входящее текстовое сообщение получает новый ответ внизу чата; прежнее меню
удаляется только после подтверждения новой отправки. Нажатая кнопка обновляет
то сообщение, на котором находится. Неопределённая отправка автоматически не
повторяется. Приватная диагностика не отправляет сообщения и не меняет профиль.

Для энергетиков предлагается только объём. Весовые энергетические смеси из
прайсов не считаются напитками. «Энергетик монстр 0.5» означает Monster 500 мл;
неявная единица применяется только к дробному объёму в таком контексте, а не к
произвольному товару. Указанный бренд используется как узкий индекс поиска.

## Общий запрос курицы и выбор в корзине

«Курица» охватывает связанные пищевые продукты: мясо, субпродукты, колбасу,
сосиски и снеки со вкусом курицы. Корма и игрушки не входят в обычный пищевой
поиск. «Свежая курица» оставляет прежние ограничения сырого мяса; вид можно
уточнить кнопками. Явно выбранный товар в корзине не заменяется.

Неуточнённая строка корзины остаётся названием запроса. В расчёте показана
нижняя граница «от», без выдачи самой дешёвой позиции за выбор пользователя.
Кнопка «Выбрать» открывает все совпадения этой строки в выбранной сети.
Приватное название строки не передаётся сервису перевода.

## Замена выбранной позиции

В карточке корзины кнопка «Выбрать другой товар» снимает прежний выбор упаковки,
сохраняя исходный запрос и количество. Затем можно открыть уточнения и выбрать
новый вариант. При сбросе идентификатор позиции меняется атомарно: старые кнопки
выбора, удаления, количества и повторного сброса больше не меняют эту позицию.
Проверка всегда ограничена владельцем корзины; новая строка не добавляется.

Неполное сравнение называет до трёх отсутствующих позиций и количество остальных.
Предварительная стоимость обозначается «от», включая кнопку покупок в разных сетях.

## Состав сравнения сразу на первом экране

Обзор сравнения показывает две сети на странице. Для каждой видны позиции
корзины: найденные — с количеством и ценой, отсутствующие — с явной отметкой
«не найдено». Итог неполной корзины подписан «Найденные товары». Полный список
сетей доступен через «Магазины»; прежнее скрытое ограничение четырьмя удалено.
Большие корзины листаются по пять позиций независимо от страницы магазинов.
Кнопка конкретной сети открывает подробности и подбор упаковок, а не служит
единственным способом узнать состав сравнения.

Русские «сливы» и «соус песто» распознаются по сербским наименованиям. Общий
поиск слив исключает томаты сорта «сливар», ракию, каши и изделия со вкусом
сливы; песто не подменяется паштетом, сыром или выпечкой с песто.
Продуктовые запросы молока и слив исключают посуду, кухонные приспособления
и косметическое молочко. Запросы с явно
указанным типом изделия сохраняют собственную логику поиска. Прайсы и наличие
по-прежнему требуют проверки даты и упаковки.

Диагностика дополнительно сравнивает виртуальную корзину из четырёх публичных
запросов (энергетик, молоко, сливы, соус песто), возвращая покрытия сетей.
Она не записывает корзины пользователей и не отправляет им сообщения.

## Упаковка за предварительной ценой

В обзоре и подробностях неуточнённой корзины рядом с ценой показывается размер
реального предложения, использованного в оценке. Например: «250 мл» или
«кисломолочное · 180 г». Параметры извлекаются из публичного названия;
неизвестная упаковка не придумывается. Выбор товара не подтверждается автоматически.
Личные запросы не передаются в переводчик, дополнительных запросов перевода нет.

У молока есть необязательный выбор вида: питьевое, кисломолочное, шоколадное.
Питьевое не включает kiselo mleko, шоколадное, растительное, сухое и сгущённое
молоко. Без выбора вида «Показать все» сохраняет широкий поиск. Работают и явные
запросы «питьевое молоко», «обычное молоко», «кисломолочное молоко»,
«шоколадное молоко». Указанный вид повторно не спрашивается; бренд, упаковка
и жирность уточняются независимо. Выбор при уточнении корзины сохраняет её
позицию и количество. Главное меню не расширяется.

Проверка упаковок дополнительно выявила алкогольные предложения со сливой,
где в заголовке нет слова «ракия». Обычный запрос слив исключает жидкие
упаковки, штрудели, пироги и мармелад; явные запросы изделия или жидкого объёма
сохраняют свой поиск. Публичные контрольные названия видны в приватной диагностике.

## Цена за единицу и сохранённые критерии корзины

Карточка, результаты поиска и сравнение показывают RSD/кг или RSD/л при
однозначном размере в публичном названии. Считается текущая цена с действующей
скидкой; количество упаковок не меняет цену единицы. Поддерживаются г/гр/gr,
кг, мл, cl, л, десятичная запятая и явные наборы 6×250 мл. Код MK24 не считается
числом упаковок. Неизвестные/противоречивые размеры, смешанные комплекты и
ёмкость посуды не превращаются в расчёт. Поле единиц самого прайса недостаточно
надёжно для вывода размера. Итог корзины остаётся суммой покупаемых упаковок.

В уточнениях позиции есть «Сохранить для сравнения». Сохраняются выбранные вид,
бренд, упаковка, жирность и цоколь; конкретный товар при этом не выбирается.
Уточнения действуют при последующих сравнениях во всех сетях, видны в корзине
и редакторе позиции. Можно сбросить их отдельно. Выбранный конкретный товар
сравнивается точно; его явная замена сбрасывает прежний выбор и уточнения.

Критерии хранятся отдельно от профиля в sd_basket_filters с ключом uid/id.
Сохранение разрешено лишь для собственной неуточнённой позиции. Подтверждение
товара проверяет соответствие критериям и атомарно проверяет их неизменность:
старая кнопка и параллельное изменение не обходят ограничения. Очистка отменяет
старый черновик. Удаление позиции/аккаунта удаляет связанные критерии. Данные
существующих корзин и количество сохраняются без изменения схемы sd_basket.

Рядом с оценкой подписываются известные различия: сливы/чернослив, филе,
крылья, субпродукты, колбаса, снеки со вкусом курицы. Неизвестный вид не угадывается.

## Словарь и резервный перевод

Русские формы, сербская латиница/кириллица и распространённые английские
названия сопоставляются общим словарём. Пончик/донат/donut/doughnut/krofna
ищут выпечку; вода Donat Mg остаётся доступна явным запросом марки воды.
Посуда, формы и светильники с рисунком пончика не считаются пончиками.
Петрушка/persun/parsley не подменяется сыром с петрушкой. Продуктовые запросы
исключают обнаруженные бытовые и косметические совпадения, сохраняя их явный поиск.

Переводчики работают с публичными наименованиями. При сбое, квоте или проблеме
кэша используется словарный перевод известных слов и фраз с сохранением бренда,
цифр и оригинала. Это резервный, иногда частичный перевод. Неизвестные слова
не выдумываются. Проверка отклоняет подмену г/кг на мл/л и выдуманный размер;
старый кэш с такой ошибкой перепроверяется. Личные запросы не отправляются.

Отчёт проверки каталога: [CATALOG_AUDIT.json](CATALOG_AUDIT.json). Он фиксирует
проверенные прайсы, их даты, покрытие контрольных слов и расхождения метаданных;
нахождение контрольных запросов не означает проверки всех возможных формулировок.
Повторение без публикации цен:

```sh
python3 -m collector.audit_snapshot --output work/catalog-snapshot.json
node tools/catalog_audit.mjs work/catalog-snapshot.json work/catalog-audit.json
```


## Быстрые интерактивные экраны

Рабочие панели кодируются локально в JPEG (качество 88), без Canvas, HTTP,
Node Buffer и платных сервисов; PNG остаётся для экспорта и уведомлений о банах.
Контрольный экран 960 × 552: 175 477 байт вместо 354 678 PNG. Библиотека
jpeg-js 0.4.4 закреплена в lockfile, в Cloud попадает только собранный кодировщик;
декодировщик используется лишь в локальном тесте. Лицензия — tools/licenses/jpeg-js.txt.
Версия изображения включена в ключ Telegram file_id, старый PNG не подменяет
новый формат. Оформление, размеры и иконки сохранены; JPEG с потерями, поэтому
сравнивается читаемость, а не побайтовое совпадение.

Подсчёт сетей использует узкую SQL-проекцию с ID/сетью/ценой. Те же условия
свежести, фильтры, устранение повторов, диапазоны и количество предложений
сохраняются. Загрузка подробностей нужна только при открытии списка товаров.

В SQLite хранится по одному служебному замеру для четырёх типов экранов:
networks/products/card/other. Только время записи и числовые длительности
запроса, поиска/подготовки карточки, рендера и вызова Telegram. Текст поиска,
имена, ID пользователей, содержимое корзины и ответы внешних сервисов не пишутся.
Последний замер перезаписывается; служебный diagnose читает его без сообщений
пользователям. Это время обработчика до финальной очистки, не время доставки
до телефона, и не история действий пользователя.

## Сопоставимая корзина и нужное количество

В корзине `молоко 2 л` означает требуемый суммарный объём, `кофе 500 г` —
требуемый вес. `× 2` повторяет это количество. Подбор снимает объём/вес с
поискового запроса, а цену считает как число целых упаковок: ceil(нужно/размер).
Для одной строки и одного формата сети выбирается самый дешёвый по итогу
вариант одинаковых упаковок. Смеси разных SKU/размеров в одной строке не
оптимизируются. Показываются нужное количество, число упаковок, их размер и
получаемое количество; излишек при округлении явно виден. Неизвестный или
противоречивый размер из названия не угадывается по ненадёжному полю единиц.

Прямое добавление конкретной карточки по-прежнему означает упаковки/штуки.
Подтверждение товара для строки с нужным объёмом/весом сохраняет это количество;
неизвестная/другая размерность не допускается. Кнопки изменения количества
повторяют указанное в строке количество. Исходные строки и количество в базе
не переписываются; новая интерпретация действует и для старых строк с явным
размером. Поиск одного товара вне корзины продолжает ограничивать размер
упаковки, если пользователь указал его в запросе.

Подтверждённый product/SKU сравнивается точно. Остальные строки — предварительный
подбор (~), даже если найден один подходящий вид. Для молока, курицы, кофе и мяса
выделяются наблюдаемые классы; бренд SPASOJEVIC не превращает молоко в соевое,
а «молотый из зёрен» не означает кофе в зёрнах. Если кандидаты несовместимы по
виду или упаковке без заданного общего количества, строка предлагает уточнение
и не входит в итог. Широкий обычный поиск сохраняет все виды, включая снеки,
колбасу, филе и субпродукты. Это простые защитные правила, не универсальная
семантическая классификация каждого товара каталога.

Для количества и классов читаются все кандидаты в пределах 1000, страницами
по 200. При превышении выдаётся просьба уточнить запрос, а не усечённый
«самый дешёвый» результат. Во время расчёта проверяются поколения источников.
Кэш привязан к версии алгоритма, дате, составу, количеству, фильтрам и поколениям.
Когда выбранных SKU нет, запрос их предложений не выполняется.

Итог сначала показывает лучшую полную корзину в одной сети, сбор по отдельным
предложениям нескольких сетей и число не найденных/требующих уточнения строк.
Далее сохранены две сети и до пяти позиций на страницу: видны цены и причины
отсутствия каждой строки. Полные, частичные и неоднозначные результаты разделены;
нулевая рассчитанная часть не выглядит бесплатной корзиной. Экономия относительно
одной сети вычисляется только после подтверждения всех SKU и полного расчёта,
без учёта поездок. Сравнение не обещает наличие и цену конкретного филиала.
Главное меню по-прежнему содержит четыре раздела.

## Оформление для демонстрации — 21.10.2026

Главный экран сохраняет четыре пользовательских раздела и полную иллюстрацию.
На рабочих экранах шапка ниже на 98 пикселей; размер текста сохранён.
Длинное название товара находится под коротким заголовком карточки, а не
занимает несколько строк крупного заголовка. Кэш статичных изображений имеет
новую версию; клавиатура и права по-прежнему строятся отдельно.

«Открыть» в результатах ведёт к карточке; «Добавить в корзину» подтверждает
добавление. После успешного сохранения сообщение видно в корзине один раз.
Устаревшее предложение получает отдельное объяснение без ложного подтверждения.
На вводе списка есть возврат к корзине; выход отменяет ожидание списка.
Номерные кнопки корзины содержат краткое название, а стрелки списков подписаны.
Пустой экран уведомлений предлагает найти товар вместо перехода к пустому списку.

Состав, пропуски, неоднозначные позиции и предварительные цены сравнения
сохранены. Поиск, правила подбора, роли, баны и каталог не менялись.
Новых пользовательских функций и разделов нет.


## Словарь, зависимые уточнения и контроль каталога — 21.10.2026

Проверенные разговорные формы и опечатки добавлены в локальный словарь:
например, «огурчики», «крофне», «пертушка», «энергитик». Произвольные бренды
и штрихкоды не расширяются нечётким поиском. Все словарные формы проверяются
на совпадение групп поиска с основным словом; «изюма», «йогурта» и
«наждачная» исправлены после полного аудита.

Виды товара предлагаются только при наличии в выборке каталога. Выбор вида
или бренда сразу обновляет зависимые характеристики на экране. Уточнения
необязательны, «Показать все» сохраняет широкий поиск. Выборка до 120 строк
не гарантирует перечень всех существующих брендов: сами результаты поиска
не ограничиваются этой выборкой.

Размер упаковки проверяется одним набором правил для вопросов, единичной цены
и корзины. Источник и исходное название сохраняются. Вместимость посуды и
характеристики техники не считаются количеством содержимого; явный поиск
кружки на 500 мл остаётся доступным. Сухие напитки, детские смеси, мороженое,
кокосовое масло и другие допустимые формы сохраняют свои единицы. Сомнительная
размерность не переводится из массы в объём. В карточке есть предупреждение,
неподтверждённый размер исключён из расчёта нужного количества и фильтра упаковок.

В служебном поле `_measure` хранится проверенная величина целой упаковки,
в том числе 6 × 250 мл = 1,5 л. У неё есть поисковые термины и SQL-проверка
точного размера. Старые строки дополняются порциями, без изменения названия,
цены, ID или пользовательских корзин; возобновлённый старый импорт проверяется
до публикации поколения. Кэш сравнения использует новую версию.

Обзор корзины показывает для каждой сети количество рассчитанных, отсутствующих
и требующих уточнения позиций. При неоднозначной упаковке подробности называют
размеры, а не бессодержательный вариант «товар». Полнота расчёта, порядок сетей,
отделение частичных итогов и запрет выдуманной экономии сохранены.

Владелец открывает «Состояние магазинов» → «Проверка каталога». Отчёт содержит
проверенные строки, подозрительные размерности, расхождения единиц источника,
повторы/конфликты парсера, скачки обычной цены в три раза и более при совпадении
ID и названия, сокращение каталога более чем вдвое. Вместимость посуды не
объявляется ошибкой каталога. Новые поколения проверяются при завершении импорта;
у неизменившегося прайса обновляются счётчики CSV. Для существующей базы есть
приватная операция `quality` с порциями по 500 и проверкой поколения. До пяти
порций объединяются в один вызов, каждая сохраняет свою контрольную точку;
фиксированные выражения повторно используются.

Сохраняется один итог и один незавершённый проход на сеть, примеров не больше
шести. Права проверяются по числовому ID владельца, включая поддельные callback.
Проверки не используют пользовательские поиски и не отправляют тестовые сообщения.
Свежесть прайсов контролирует прежнее независимое задание. Цена автоматически
не исправляется; предупреждение о скачке означает необходимость проверки.

Сухое и кисломолочное молоко распознаются в обоих русских порядках слов.
Граммы для этих форм допустимы; выбранное питьевое молоко использует объём.
