# Интерфейс покупок

В обычном меню четыре пункта: поиск, корзина, уведомления и помощь. Сотрудникам
доступен отдельный вход в администрирование согласно их полномочиям.

Все основные экраны оформлены картинками с кнопками: компактная иллюстрация,
крупный заголовок, локально нарисованные иконки. Изображение текущего сообщения
заменяется при переходе. В случае подтверждённого отказа картинки работает
текстовый вариант с теми же действиями. Внешний хостинг изображений не нужен.

- Поиск: название → сеть с диапазоном цен → три товара на странице → карточка.
  Короткие кнопки с номером и ценой соответствуют товарам на картинке.
  Русское название показано первым, сербский оригинал — после `/`.
- В карточке: цена, магазин, дата, характеристики. Добавление в корзину и
  отслеживание находятся рядом. Цены отдельных форматов сети открываются
  отдельно, если для товара есть несколько таких прайсов. Это не адреса филиалов.
- Корзина: список через запятую или с новой строки → сравнение. На странице до
  пяти позиций; номерная кнопка открывает количество, уточнение упаковки и удаление.
  Возврат к корзине отменяет ожидание ввода списка.
- Сравнение: сначала суммы лучших четырёх сетей. Неполные корзины явно помечены
  «Только N из M». Кнопка магазина открывает состав с итогом, по пять позиций.
  Покупки в разных сетях доступны отдельно, когда найден весь список.
- Уведомления: статус, количество товаров и одна кнопка включения/выключения.
  После нажатия «Следить» можно сразу включить уведомления. Список отслеживания
  разбит на страницы по пять товаров.
- Помощь: три коротких сценария и связь с поддержкой. Ссылки на прайсы, сведения
  о машинном переводе и удалении данных находятся в «О ценах и данных».

## Названия товаров

Переводятся только публичные названия из каталога. Личные поисковые запросы и
неуточнённые строки корзины внешним сервисам не отправляются. Бренд, сербский
оригинал и идентичность товара сохраняются; числовые характеристики проверяются.
Google Translate используется с бесплатным резервом MyMemory, без ключей и
платной подписки. При квоте сервис временно не вызывается. Если перевод не
получен, показаны «Перевод недоступен / сербское название» и рабочие кнопки.
Для простых частых названий есть локальный словарь.

Общий кэш ограничен 3 000 публичных названий, срок перевода — 30 дней. Атомарные
аренды подавляют параллельные запросы одного названия; общий лимит — 120 новых
переводов в минуту, не более трёх одновременно на один экран. Повтор после сбоя
не раньше минуты. Сбой кэша не блокирует поиск и карточки. В длинных списках
сокращаются обе части названия с сохранением окончания, а не только сербская.

## Проверки

`interface.test.js`, `product-names.test.js`, тесты корзины и модерации проверяют
переходы, права, сравнение неполных корзин, изоляцию личных данных, кэш, квоты,
параллельный перевод и резервный сервис. Локально просматриваются PNG.
Приватная операция `diagnose` использует виртуальный Telegram API и проверяет
экраны покупок, админку и перевод публичных контрольных названий без сообщений
пользователям и изменений корзины. Кэш перевода может пополняться.
