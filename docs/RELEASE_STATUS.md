# Состояние первой публикации

## Опубликовано и проверено

- Отдельный репозиторий `AngryVirus/serbia-deals-bot` создан и содержит проект.
- Владелец сохранил `SERBIA_DEALS_CLOUD_TOKEN`; подключение подтвердилось.
- Код опубликован в Telegram Serverless: ревизия 1, 14 модулей, `active=false`.
  https://github.com/AngryVirus/serbia-deals-bot/actions/runs/39401054281
- Первый импорт завершился частично: Lidl — 2 992 предложения,
  Maxi / Delhaize — 25 658. Okov не опубликован.
  https://github.com/AngryVirus/serbia-deals-bot/actions/runs/39401445493
- Проверка Cloud подтвердила 28 650 опубликованных предложений,
  оба источника от 20.10.2026, пустую очередь уведомлений и `active=false`.
  https://github.com/AngryVirus/serbia-deals-bot/actions/runs/39403471485
- После отдельного согласия владельца импорт Okov повторён успешно:
  75 453 предложения от 20.10.2026, все приняты, конфликтов и отклонений нет.
  https://github.com/AngryVirus/serbia-deals-bot/actions/runs/39406659602
- Итоговая проверка подтвердила 104 103 опубликованных предложения,
  все три источника со статусом `ok`, очередь пуста, `active=false`.
  https://github.com/AngryVirus/serbia-deals-bot/actions/runs/39407234678
- Локально и в повторном импорте проходят 12 Python-тестов и 23 JavaScript-теста.
- Проверки секретов и зависимостей проходят; npm audit — 0 уязвимостей.
- Проверено 47 публичных источников, 32 успешно разобраны локально.
  Это не означает, что все эти магазины уже загружены в Cloud.
- Локальная объёмная проверка: 104 091 предложение, см. `PERFORMANCE.json`.

## Исправления после первой проверки Cloud

Ветка `fix/cloud-runtime-probes`, PR #4:
https://github.com/AngryVirus/serbia-deals-bot/pull/4

Проверка больших каталогов разбита на страницы по 1 000 записей;
очистка старых поколений — до 250 предложений за вызов, с блокировкой источника.
Текущий каталог, незавершённый импорт и другие источники защищены отдельными тестами.
Счётчики привязаны к поколению каталога. Диагностика использует только фиксированные
категории и слова, не публикует исходные ошибки, запросы или секреты.

Владелец дал отдельное согласие на повторный импорт Okov с удалением
только его устаревших технических копий прайса порциями до 250 предложений.
Повторный импорт завершился успешно; блокировка автопроверки для этого
согласованного действия устранена. Исправления опубликованы в Serverless:
ревизия 2, 14 модулей, `active=false` сохранён.
https://github.com/AngryVirus/serbia-deals-bot/actions/runs/39407088906
Активация не входит в согласие на импорт.

## Внешние ограничения и оставшиеся шаги

- Cloud не вернул размер базы через PRAGMA. Доступная квота хранилища пока
  не подтверждена; полный импорт всех источников не запускался.
- Настройка защиты main через GitHub API отклонена HTTP 403
  `Resource not accessible by integration`. Ручные шаги владельца:
  `DEPLOYMENT.md`, раздел 1. Jobs `tests` и `security` уже существуют.
- Список GitHub Secrets недоступен текущему подключению (HTTP 403).
  Наличие нужного ключа подтверждено успешным использованием в Actions.
- Бот не активирован, webhook не синхронизировался, расписания не включены.
  Нужны отдельное разрешение владельца на активацию и проверка в Telegram.
- Пользовательские уведомления для теста не отправлялись.

@SerbiaJobsBot и его настройки не изменялись. Платные сервисы не подключались.
